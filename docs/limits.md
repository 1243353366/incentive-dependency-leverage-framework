# Limits of this instrument

Written down because a framework about leverage is itself a way of gaining leverage, and the
premise it is bound by is simple: **my wins should never create a future problem for me.**

## What this is

A structured set of questions: what are the incentives, who depends on whom, where the
leverage sits, what the mirror test says about your own contribution, and how you would know
you were wrong. Its value is that it slows a decision down in useful places.

## What this is not

- Not validated. There is no study behind any layer, and no outcome data.
- Not a predictor. It will not tell you what someone will do; it will tell you what you have
  not yet asked.
- Not neutral. Any framework that names tactics can be used with them. The mirror test and
  the safety gate are in the sequence deliberately, and removing them leaves something that
  reads like a manual for handling people.

## The failure this repository is exposed to

A framework that helps you arrange a situation so someone reaches your conclusion is
indistinguishable, from the inside, from clean engineering. It is not clean: it removes the
friction they needed to build the judgement, it leaves you carrying the dynamic, and it
provokes a defence reaction the moment they notice the rails. If a use of this framework only
works while the other person cannot see it, it is outside the premise above.

## What would make this more than an opinion

Someone running it prospectively on real decisions, recording the predictions the framework
implies before the outcome is known, and publishing the misses. Until that exists, treat every
layer as a question worth asking rather than a claim worth trusting.
